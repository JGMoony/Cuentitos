> 😴 **To Mimir** es un rincón digital concebido para disfrutar de relatos breves e historias infantiles antes de dormir, acompañados de reproducciones de audio narradas y una interfaz suave orientada al descanso.

---

## Características Destacadas

- **Audiocuentos Integrados:** Reproductor de audio HTML5 nativo para escuchar las historias mientras lees.
- **Modo Lectura Nocturna:** Paleta de colores cálidos y oscuros optimizada para evitar la fatiga visual.
- **Biblioteca Clasificada:** Historias organizadas por duración de lectura, género y temática.
- **Gestión Multimedia:** Carga y sincronización eficiente de plantillas y assets de audio.

---

## Stack Tecnológico

- **Backend:** Python / Django Web Framework
- **Frontend:** HTML5 Semántico, CSS3, JavaScript
- **Base de Datos:** MongoDB / SQLite
- **Reproducción de Medios:** Audio HTML5 API & Django Templates
